## 多固定返回值（434）

`statements/fixed_results.rs` 仅接受当前空闲槽开始、原 CALL 返回范围完全匹配
的多固定结果，保留每个 SSA 定义及固定槽绑定。即使第一结果完全未读，
`local unused, owner = get()` 也必须仍有两个绑定；删除 unused 会改变 CALL
宽度、nil 填充及 GC 可见的对象存活时间。

普通三结果调用先与冻结的 generic-for 协议匹配；不符合迭代协议时才作为三
绑定声明。开放参数的最终消费者仍采用原固定结果宽度。

434 的 3 项常规测试覆盖 3 份原创源码的 18 个配置：固定 2/3/4 结果、原生
generic-for 三结果、开放参数到固定结果、返回不足时的 nil 填充及未读对象
存活轨迹均相同；全部 builder LIR、常量和 maxstack 完全一致。4 个篡改
CALL 结果宽度/生产槽的变体不能获得源码帧证书。

## 短路 AND（435）

`statements/and_guards.rs` 匹配多个条件共享同一失败后继的协议，按原次序
组成 `and`。例如 `if kind == 1 and check() then A() elseif ... end` 的第二
条件失败时必须进入 elseif，不能改写为两层普通 if。then/else 正文各自只
恢复一次，未知分支目标和临时消费不产生证书。

435 的 2 项测试覆盖 3 份源码的 18 个配置，验证两/三条件、计算条件位于首项
或后项，以及每一种短路失败、elseif 与 else 路径。整个 builder LIR、常量、
栈槽和运行时/GC 轨迹均一致。

## 比较结果物化（437）

`statements/boolean_values.rs` 只识别标准比较分支、false LOADBOOL、同一原始
LOADBOOL 的跳过指令及 true LOADBOOL。两个写必须落在同一槽，且不得有其它
控制边进入物化分支。目的槽可以是当前空闲槽的新声明，或既有固定槽局部的
写回；单纯的分支条件不能代替这些物理布尔写入。

437 的 3 项测试覆盖 3 份正向源码的 18 个配置，完整比较 LIR、常量、栈槽与
运行时/GC 轨迹；包括 free 槽声明、既有局部写回、两个计算操作数和纯既有
绑定比较，以及谓词反向。另 6 个配置保守拒绝给未证明的 `local copied = left`
后接比较颁发源码帧证书，避免把 MOVE 裸引用折入条件而删除原始写槽。

## 显式比较求值方向（440）

规范化 LT/LE 的操作数位置并不总是源码求值顺序。新的
`RelationalOperandOrder` 由原始相邻临时槽、表达式 origin 和常量池首次引用
证据确定，经 HIR/AST 传到输出层。例如原始调用先读取新的方法名，之后才
比较新常量 0 时，必须输出 `call() > 0`，才能同时保留调用槽与常量次序。
`0 < oldCall(newString)` 的旧 callee 已见过，则还须证明 0 早于新字符串入池。
两个计算操作数按原始实际写槽选择方向；EQ 不通过交换两端来修补顺序。

440 的 3 项测试覆盖 11 份原创源码、66 个配置：4 种字面量与 callee/参数
首次入池形状，4 种双计算操作数的 `<`、`>`、`<=`、`>=`，以及 3 种参数与
调用结果比较的 `__eq` 参数次序。完整 builder 的 LIR、常量、maxstack 与
运行时/GC 事件全部一致。
